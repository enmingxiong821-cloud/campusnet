目标链路是：通电 → 程序自动运行 → 自动认证你配置好的网络；机器开不开机由你远程决定 （关机 / 唤醒 / 体检在「电源」页操作，开机需要 BIOS 上电自启 / 智能插座 / WOL 之一）。 默认载体写在当前用户启动文件夹，是「登录后」语义；想要「通电就自动连」， 点上方的「开启」注册计划任务——开机触发、无论是否登录都运行， 需要管理员权限（会弹一次 UAC 并要你输入当前 Windows 账户密码）。 Linux 走 systemd 用户单元（无则退化为 XDG autostart），macOS 走 LaunchAgent。

电源控制

远程开机 · 三层方案（按「宿舍断电」现实排序）

L1 · 来电自启 + 智能插座 断电场景首选
BIOS 设「断电恢复 = Power On」，插座重新上电后机器自动开机；宿舍整体断电时插座也要能联网，需自带 4G/SIM 的插座。
L2 · 常开跳板 + WOL 有电但关机 / 睡眠
宿舍里留一台常开小设备（树莓派 / 旧路由 / 旧手机）发魔术包叫醒这台电脑（需同一局域网）。
L3 · 同网段手机 App 临时应急
手机连同一 Wi-Fi，用 WOL App 填下面的 MAC 直接唤醒。
