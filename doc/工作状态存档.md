## 三、本轮修复过的问题

按根因修复，不是表面兜底：

1. **`crypto.obfuscate` 遇中文/emoji 崩溃** —— 原本按 `ord(c)` 逐字符异或，
   非 BMP 字符超出字节范围。改为先 UTF-8 编码再对字节流异或。
2. **`parse_forms` 完全解析不出表单** —— 原本用 `_TAG_END_RE.split()` 切分，
   会把 `<form>` 开标签本身一起切掉。改为按 `<form>` 位置切片 + `finditer` 定位闭合标签。
3. **`/api/accounts/{id}/login` 返回 500** —— 从路径末段切字符串取 ID，
   遇到尾部 `/login` 就切成 `"login"` 导致 `int()` 失败。改为从路由参数 `ctx["params"]["id"]` 取值。
4. **账号字段误判为 `user_ip`** —— Dr.COM 表单里 `user_ip` 带默认值且命中字段名启发式。
   改为跳过有默认值的隐藏字段。
5. **密码字段误判为 `hiddenPwd`** —— 按字段名匹配先命中了隐藏域。
   改为优先按 `type="password"` 判定。
6. **网关推导错位** —— 固定推 `x.y.z.1`，但 `/16` 掩码下网关在 `x.y.0.1`。
   改为 `gateway_candidates()` 同时给出两个候选，由扫描去判定。
7. **扫描可能空转数十秒** —— 逐网关全量扫描。改为命中即停 + 每网关限额。
8. **启动脚本在中文路径下失效** —— `PYTHONPATH` 含中文时被 shell 截断。
   改为 `utils/run.py` 在 Python 内部处理 `sys.path`。

## 四、还有什么待验证

### 高优先级

- [ ] **真实门户端到端验证** —— 需要一台处于「已掉线、需 Web 认证」状态的机器。
      当前机器已放行，无法触发登录路径。这是唯一的关键阻塞。
- [ ] **浏览器登录模式实测** —— Playwright 代码路径从未在真实门户上跑过，
      字段选择器、超时、验证码处理都是理论正确。
- [ ] **中文门户编码** —— 部分门户返回 GBK/GB2312。当前 `_fetch` 统一按 UTF-8 解码，
      GBK 页面会出现乱码，可能导致表单字段名识别失败。

### 中优先级

- [ ] **验证码门户** —— 已识别到验证码就自动切浏览器模式，但纯文本验证码无解，
      需要接打码平台或改为人工介入。
- [ ] **多网卡场景** —— `local_ipv4()` 用 UDP connect 猜出口 IP，
      VPN/多网卡下可能猜错网关。
- [ ] **并发多账号** —— `check_all` 是串行的，多账号时单轮耗时累加。

### 已明确排除

- 不做 802.1X（客户端证书/驱动层）认证 —— 本项目定位是 Web 门户认证。
- 不做 MAC 绑定绕过 —— 超出合法使用范围。

## 五、下一步建议

### 立即可做（不需要掉线环境）

1. **补 GBK 解码**：`portal._fetch` 增加 charset 嗅探，从 `Content-Type` 或 `<meta>` 读取编码，
   回退 UTF-8。这是真实环境里最容易踩的坑。
2. **补文档**：把 `doc/` 填上（架构说明、API 清单、常见门户适配表）。
3. **补原型**：`prototype/` 里出一份静态高保真原型，供确认 UI 方向。

### 需要掉线环境才能做

4. **在断网机器上跑 `python utils/run.py discover`** —— 自动识别门户与字段，
   拿到输出后即可生成账号配置。这是适配新校园网的标准流程。
5. **用真实门户验证 HTTP 登录**，重点看隐藏字段是否带全（Dr.COM 的 `0MKKey`、
   `user_ip`、`user_mac` 缺一个都会被拒）。
6. **验证浏览器登录**，重点看验证码与 CAS 跳转。

### 适配新校园网的推荐流程

```
1. 拔网线/断开认证 → 确认探活变为 offline
2. python utils/run.py discover          # 自动识别厂商、路径、字段名
3. python utils/run.py add --name X ...  # 用上一步的输出建号
4. python utils/run.py check --account 1 # 立即验证
5. python utils/run.py serve             # 启动控制台长期运行
```

若 `discover` 失败，手工填两个值即可：门户地址 + 登录方式（`http` / `browser`）。
字段名留空会自动识别，识别错了再手工指定。
