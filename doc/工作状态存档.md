- 本轮新增：`credentials.py` + `crypto.encrypt_blob/decrypt_blob`，以及 CLI 的
  `cred export/import`。背景是 Windows 上密码走 DPAPI（绑当前用户与这台机器），
  只备份 `database/campusnet.db` 换机后解不开。封套用 PBKDF2-HMAC-SHA256（默认 20 万次迭代）
  派生密钥 + HMAC-SHA256 流加密，encrypt-then-MAC，导入按「同名 + 同账号」覆盖、
  其余新增，重复导入不产生重复账号；支持 `--dry-run` 与 `--passphrase-file`。
  导出文件在 POSIX 上收紧到 0600，且明文提示「等价于明文口令，迁移后请删除」。
- 本轮新增：自启动语义准确性。`bootstart` 增加 `is_wsl()`、`has_desktop_session()`、
  `verify_launch()` 与 `BootStatus.effective`：安装前干跑一次「解释器 + 导入 campusnet」
  自检（路径写错、虚拟环境被删这类问题不会再拖到重启后才发现）；WSL 且无 systemd 时
  明确拒绝安装 XDG autostart；status 会区分「已写入」与「在本机是否会生效」，
  `activate()` 与 doctor 分别给出警告与 FAIL。
- 本轮新增：Windows 计划任务模式 `bootstart install --mode task`（开机触发、
  无论是否登录都运行），这是「有电就自动连」的落地载体——默认的启动文件夹是
  「登录后」语义，机器停在登录界面时不会认证。密码只在注册时经 stdin 交给
  PowerShell/任务计划程序，不进命令行与环境变量；status 优先报告已注册的任务，
  uninstall 同时清理任务与启动项，doctor 会据 `effective` 判断是否真的会生效。
- 本轮新增：`power.py` 与 `POST /api/power/{off|reboot}`（必须 `confirm=true`）、
  CLI `power off|reboot|wake`，以及控制台「设置」页的远程关机/重启按钮——
  手机浏览器打开控制台即可一键操作。`power wake --mac` 发 WOL 魔术包，供宿舍里
  常开的树莓派/路由器替用户按电源键；真实开机仍须 BIOS 上电自启或智能插座。
- 本轮新增：简化使用与多端互通。`shortcut` 子命令为每种用法在桌面生成快捷方式
  （Windows .lnk 经 PowerShell/WScript.Shell，用 `cmd /k` 保留窗口；macOS/Linux
  生成 .command/.desktop），`console` 打开控制台、`logs` 看最近日志、`access`
  一次列出本机/局域网/Tailscale 地址与控制台令牌，专门解决「手机该填什么」。
- 本轮修复与新增（按浏览器批注）：`bootstart install --mode task` 之前有两个真实
  缺陷——用 `powershell -Command -` 从 stdin 读脚本会把密码当成命令执行，
  且子进程继承的 PSModulePath 指向打包运行时、导致自带模块加载失败。改为
  `-Command <脚本>` + 密码经环境变量传递 + .NET 构造 SecureString + 补系统模块路径；
  `-UserId` 修正为 PS 5.1 的 `-User`。实测非管理员账户注册会被系统拒绝，已改为
  明确提示并另出一个自我提权（弹 UAC）的桌面快捷方式。
- 本轮新增：`GET /api/power/info` 与控制台「怎么远程开机」按钮，列出网卡 MAC
  （已连接优先）与唤醒命令；控制台说明文字改为「通电 → 自动认证，开关机由你远程决定」。
- 本轮新增：一键配置。`run.py setup`（新模块 `setup_flow.py`）把首次使用要手动做的事
  串成一条命令：检查 Python 版本 → 生成桌面快捷方式 → 验证可选的浏览器依赖 →
  跑一遍 doctor → 直接给出下一步。仓库根新增 `install.bat` / `install.sh` 薄封装，
  双击即用；`release.yml` 把这两个脚本一起打进 zip。运行本体本就只用标准库，
  所以默认不创建虚拟环境、不下载任何东西。
- `.gitignore` 的锁规则收窄为 `database/*.lock`——写成 `*.lock` 会连带忽略
  `uv.lock` / `poetry.lock` 这类必须入库的依赖锁文件。
- 本地全量测试通过（跳过项为需要显式开启的浏览器用例）；具体数字以运行输出为准，

## 三、本轮修复过的问题

按根因修复，不是表面兜底：

1. **`crypto.obfuscate` 遇中文/emoji 崩溃** —— 原本按 `ord(c)` 逐字符异或，
   非 BMP 字符超出字节范围。改为先 UTF-8 编码再对字节流异或。
2. **`parse_forms` 完全解析不出表单** —— 原本用 `_TAG_END_RE.split()` 切分，
   会把 `<form>` 开标签本身一起切掉。改为按 `<form>` 位置切片 + `finditer` 定位闭合标签。
3. **`/api/accounts/{id}/login` 返回 500** —— 从路径末段切字符串取 ID，
   遇到尾部 `/login` 就切成 `"login"` 导致 `int()` 失败。改为从路由参数 `ctx["params"]["id"]` 取值。
4. **账号字段误判为 `user_ip`** —— Dr.COM 表单里 `user_ip` 带默认值且命中字段名启发式。
   改为跳过有默认值的隐藏字段。
5. **密码字段误判为 `hiddenPwd`** —— 按字段名匹配先命中了隐藏域。
   改为优先按 `type="password"` 判定。
6. **网关推导错位** —— 固定推 `x.y.z.1`，但 `/16` 掩码下网关在 `x.y.0.1`。
   改为 `gateway_candidates()` 同时给出两个候选，由扫描去判定。
7. **扫描可能空转数十秒** —— 逐网关全量扫描。改为命中即停 + 每网关限额。
8. **启动脚本在中文路径下失效** —— `PYTHONPATH` 含中文时被 shell 截断。
   改为 `utils/run.py` 在 Python 内部处理 `sys.path`。
